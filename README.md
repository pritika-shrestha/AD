## Alzheimer’s Disease Detection and Prediction

### Project Description:
This project focuses on the **detection and prediction of Alzheimer’s disease using deep learning and machine learning models**.

In this project, two different approaches were trained and compared:
1. **Hybrid CNN + SVM**
2. **Vision Transformer (ViT)**

The models were trained using the dataset and their performance was evaluated based on the obtained results. The main purpose of the project is to understand their performance in Alzheimer’s disease detection.

### Objectives
* To prepare and preprocess the dataset.
* To train a hybrid **CNN + SVM** model.
* To train a **Vision Transformer (ViT)** model.
* To test both models using the test data.
* To analyze the results obtained from both approaches.

##  Models Used
### 1. Hybrid CNN + SVM
A **Convolutional Neural Network (CNN)** was used for feature extraction, and the extracted features were then used with a **Support Vector Machine (SVM)** for classification.

### 2. Vision Transformer (ViT)
A **Vision Transformer (ViT)** model was trained for image-based Alzheimer’s disease detection. Its results were then compared with the hybrid CNN + SVM approach.

##  Project Workflow

6. ViT model training
7. Model testing
8. Performance evaluation

##  Conclusion
This project explores two different approaches for Alzheimer’s disease detection: **Hybrid CNN + SVM** and **Vision Transformer (ViT)**. Both models were trained, tested, and compared based on their performance. The project helped us understand the differences between traditional deep learning approaches and transformer-based models for image classification.
